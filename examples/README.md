# Example Skills

This directory contains complete, working skill examples you can learn from and use.

## Examples

| Skill | Directory | Description |
|-------|-----------|-------------|
| Weather | `weather/` | Get weather info using wttr.in API |
| Image Generation | `image-gen/` | Generate AI images with DALL-E |
| Data Processing | `data-processing/` | Transform data between formats |

## Installing an Example

Copy an example to your skills directory:

```bash
# Install weather skill
cp -r examples/weather ~/.openclaw/workspace/skills/

# Install image generation skill (requires API key)
cp -r examples/image-gen ~/.openclaw/workspace/skills/
```

## Learning from Examples

Each example demonstrates different aspects of skill development:

- **weather**: Simple API integration, no authentication
- **image-gen**: API with authentication, configuration required
- **data-processing**: Multiple tools, complex workflows

Study the `SKILL.md` files to understand how each skill works.
