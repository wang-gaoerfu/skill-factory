# 阶段2：老人陪伴详细设计

**版本**：v0.1  
**日期**：2026-03-24  
**优先级**：高

---

## 一、产品定位

### 1.1 目标用户

- **主要用户**：60岁以上老人
- **付费用户**：子女
- **使用场景**：健康管理、情感陪伴、生活助手

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 健康管理 | 用药提醒、健康监测、异常预警 |
| 情感陪伴 | 日常聊天、倾听陪伴、主动关怀 |
| 生活助手 | 日程提醒、天气播报、资讯获取 |
| 家庭连接 | 连接子女、传递关心、紧急联系 |

### 1.3 与现有产品的差异

| 维度 | 智能摄像头/手环 | 本产品 |
|------|----------------|--------|
| 互动方式 | 被动监控 | 主动互动、双向交流 |
| 情感属性 | 无 | 有温度的陪伴 |
| 易用性 | 需要学习 | 语音为主，零门槛 |
| 功能整合 | 单一功能 | 健康+生活+情感一体化 |

## 二、功能规划

### 2.1 核心功能

```
老人陪伴功能：
├── 健康管理
│   ├── 用药提醒（按时吃药提醒）
│   ├── 健康监测（接入穿戴设备数据）
│   ├── 健康咨询（常见健康问题解答）
│   ├── 就医提醒（预约挂号、复诊提醒）
│   └── 紧急呼叫（异常情况通知子女）
├── 情感陪伴
│   ├── 日常聊天（陪聊、倾听）
│   ├── 主动问候（早安晚安、天气提醒）
│   ├── 兴趣话题（养生、戏曲、新闻）
│   └── 情绪关怀（察觉情绪、安抚陪伴）
├── 生活助手
│   ├── 日程提醒（吃药、锻炼、活动）
│   ├── 天气播报（穿衣建议）
│   ├── 资讯获取（新闻、养生知识）
│   └── 智能家居（语音控制家电）
└── 家庭连接
    ├── 子女动态（分享子女消息）
    ├── 视频通话（连接子女）
    ├── 紧急联系（一键呼叫子女）
    └── 生活报告（向子女汇报老人状态）
```

### 2.2 MVP功能（第一阶段）

## 四、交互设计

### 4.1 对话流程

```
老人语音输入 → 语音识别 → 意图识别 → 场景判断 → 响应生成 → 语音合成
                              ↓
                    ┌─────────┼─────────┐
                    │         │         │
                健康场景   生活场景   情感场景
                    │         │         │
                用药提醒   日程查询   日常聊天
                健康咨询   天气播报   兴趣话题
                紧急呼叫   智能家居   情绪关怀
```

### 4.2 交互示例

**场景1：日常问候**

```
小暖：王阿姨早上好呀！今天天气不错，17度，适合出去走走。您今天感觉怎么样？
老人：挺好的，昨晚睡得不错。
小暖：那太好了！对了，您的降压药今天吃了没？记得早上吃一片哦。
老人：吃了吃了。
小暖：好的，您记得多喝水，今天天气干燥。有什么需要帮忙的随时叫我！
```

**场景2：紧急情况**

```
老人：小暖，我不舒服...
小暖：王阿姨，您哪里不舒服？是头晕还是胸闷？别着急，慢慢说。
老人：头晕，有点恶心...
小暖：您先坐下休息，我已经给小王（儿子）发消息了，他马上给您打电话。如果很不舒服，记得打120。您现在能坐稳吗？
老人：能...
小暖：好，您先坐着别动，我继续陪着您。小王应该快打电话来了。
```

## 六、关键技术

### 6.1 语音交互（重点）

老人不擅长打字，**语音是核心交互方式**。

```
语音方案：
├── 唤醒词
│   └── "小暖小暖" / "小康小康"
├── 语音识别 (STT)
│   ├── 讯飞语音（中文优化）
│   ├── Azure Speech
│   └── 本地 Whisper（离线备选）
├── 语音合成 (TTS)
│   ├── 讯飞语音（自然度高）
│   ├── Azure TTS
│   └── 语速可调（老人听得清）
└── 方言支持
    └── 粤语、四川话、东北话等
```

### 6.2 健康数据接入

```
穿戴设备接入：
├── 小米手环/手表
├── 华为手环/手表
├── Apple Watch
└── 血压计、血糖仪

数据类型：
├── 心率
├── 血压
├── 血氧
├── 睡眠
└── 步数
```

### 6.3 紧急呼叫

```
紧急处理流程：
1. 检测异常（语音、健康数据、长时间无响应）
2. 确认状态（主动询问）
3. 紧急联系（自动拨打子女电话）
4. 持续关注（保持对话，安抚情绪）
5. 记录存档（供后续查看）
```
