**版本**：v1.0  
**日期**：2026-03-25  
**状态**：初稿

---

## 一、设计原则

### 1.1 核心定位

```
家长端 = 了解孩子动态 + 发现问题 + 参与成长

不是监控工具，而是：
├── 了解孩子的窗口
├── 发现问题的帮手
└── 参与成长的桥梁
```

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **一目了然** | 核心信息一屏展示，不用翻找 |
| **有行动建议** | 不只告诉发生了什么，还告诉该怎么做 |
| **尊重隐私** | 不展示完整聊天内容，只展示摘要 |
| **不打扰** | 只在重要事件时推送，避免信息过载 |
| **可控** | 家长完全控制功能开关 |

## 五、推送设计

### 5.1 推送类型

| 类型 | 触发条件 | 频率 | 示例 |
|------|----------|------|------|
| **情绪异常** | 检测到情绪异常 | 即时 | "小明今天情绪有些低落，建议关注" |

| **周报提醒** | 每周日20:00 | 每周 | "本周报告已生成，点击查看" |

## 六、隐私设计

### 6.1 不展示的内容

| 内容类型 | 原因 |
|----------|------|
| 完整聊天记录 | 保护孩子隐私 |
| 孩子的秘密 | 尊重孩子 |
| 敏感个人信息 | 合规要求 |

### 6.2 展示的内容

| 内容类型 | 展示方式 |
|----------|----------|
| 情绪状态 | 心情卡片 |
| 话题摘要 | "聊了游戏、画画" |
| 学习记录 | 掌握的知识点 |
| 情绪事件 | 事件摘要 + 建议 |

## 七、交互设计原则

### 7.1 简洁原则

- 每个页面核心信息不超过3块
- 重要信息突出显示
- 操作不超过3步

### 7.2 行动导向

- 每个问题都配有建议
- 每个建议都有话术参考
- 点击即可查看详情

### 7.3 可控原则

- 家长可以关闭任何推送
- 家长可以设置使用规则
- 家长可以导出/删除数据
