## 一、合规框架

### 1.1 适用法规

```
┌─────────────────────────────────────────────────────────────┐
│                    适用法规                                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 《儿童个人信息网络保护规定》（2019）                     │
│     └── 国家网信办，专门针对14周岁以下儿童                  │
│                                                             │
│  2. 《个人信息保护法》（2021）                               │
│     └── 敏感个人信息需要单独同意                            │
│     └── 不满14周岁需要监护人同意                            │
│                                                             │
│  3. 《网络安全法》（2017）                                   │
│     └── 网络运营者的安全保护义务                            │
│                                                             │
│  4. 《未成年人保护法》（2020修订）                           │
│     └── 网络保护专章                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 核心要求

| 要求 | 法规依据 | 我们的措施 |
|------|----------|------------|
| 监护人同意 | 《儿童个人信息网络保护规定》 | 家长授权流程 |
| 明示目的 | 《个人信息保护法》 | 清晰告知收集目的 |
| 最小化收集 | 《儿童个人信息网络保护规定》 | 只收集必要信息 |
| 安全保护 | 《网络安全法》 | 加密存储、访问控制 |
| 删除权 | 《儿童个人信息网络保护规定》 | 提供删除渠道 |
| 拒绝权 | 《个人信息保护法》 | 不强制授权 |

## 二、数据收集范围

### 2.1 收集的数据

```
┌─────────────────────────────────────────────────────────────┐
│                    收集的数据                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【必要信息】                                               │
│  ├── 孩子昵称（不收集真实姓名）                             │
│  ├── 年龄/生日（用于知识库分层）                            │
│  └── 性别（用于角色推荐）                                   │
│                                                             │
│  【自动收集】                                               │
│  ├── 对话内容（用于记忆系统）                               │
│  ├── 情绪状态（用于情绪分析）                               │
│  ├── 话题偏好（用于兴趣发现）                               │
│  └── 使用时长（用于健康监护）                               │
│                                                             │
│  【不收集】                                                 │
│  ├── 真实姓名                                               │
│  ├── 身份证号                                               │
│  ├── 学校名称                                               │
│  ├── 家庭住址                                               │
│  ├── 照片（除非家长主动上传）                               │
│  └── 联系方式（孩子的）                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 数据收集原则

| 原则 | 说明 |
|------|------|
| **最小化** | 只收集实现功能所需的最少数据 |
| **必要性** | 每项数据都有明确的用途 |
| **透明性** | 清楚告知家长收集了什么 |
| **可控性** | 家长可以控制收集范围 |

### 2.3 数据用途说明

| 数据 | 用途 | 必要性 |
|------|------|--------|
| 昵称 | 称呼孩子 | 必要 |
| 年龄/生日 | 知识库分层、成长记录 | 必要 |
| 性别 | 角色推荐 | 可选 |
| 对话内容 | 记忆系统、个性化服务 | 必要 |
| 情绪状态 | 情绪分析、家长报告 | 必要 |
| 话题偏好 | 兴趣发现、天赋分析 | 可选 |
| 使用时长 | 健康监护、时长控制 | 必要 |

## 四、数据存储与安全

### 4.1 数据存储方案

```
┌─────────────────────────────────────────────────────────────┐
│                    数据存储架构                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【存储方式】                                               │
│  ├── 结构化数据：SQLite 数据库                              │
│  ├── 向量数据：Chroma 向量数据库                            │
│  └── 敏感数据：AES-256加密存储                              │
│                                                             │
│  【存储位置】                                               │
│  ├── 默认：本地存储（~/.openclaw/data/）                    │
│  ├── 可选：云端加密存储（需要额外授权）                      │
│  └── 境内服务器（如使用云服务）                             │
│                                                             │
│  【存储期限】                                               │
│  ├── 核心档案：永久（或用户删除）                            │
│  ├── 成长记录：5年+（可设置）                               │
│  ├── 对话记录：1年（可设置）                                │
│  └── 用户可随时删除                                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 安全保护措施

| 措施 | 说明 |
|------|------|
| **数据加密** | AES-256加密存储敏感数据 |
| **传输加密** | HTTPS传输 |
| **访问控制** | 只有家长和孩子可以访问 |
| **日志记录** | 记录数据访问日志 |
| **安全审计** | 定期安全审计 |
| **数据脱敏** | 报告中不展示完整对话 |

### 4.3 数据访问权限

```
数据访问权限：

├── 孩子端
│   ├── 可以查看自己的数据
│   ├── 可以使用但看不到原始数据
│   └── 不能修改/删除（由家长控制）
│
├── 家长端
│   ├── 可以查看孩子的数据摘要
│   ├── 不能查看完整对话（保护隐私）
│   ├── 可以导出数据
│   └── 可以删除数据
│
└── 运营方
    ├── 不能查看用户数据
    ├── 只能访问脱敏统计数据
    └── 法律要求时配合提供
```

## 六、隐私保护设计

### 6.1 对话内容处理

```
对话内容处理原则：

├── 不展示完整对话
│   ├── 家长端只看摘要
│   ├── 只看话题，不看具体内容
│   └── 保护孩子的倾诉空间
│
├── 情绪事件处理
│   ├── 只报告"情绪事件"
│   ├── 不报告具体说了什么
│   └── 提供建议，让家长自己问
│
└── 秘密保护
    ├── 孩子明确说"不要告诉家长"的内容
    ├── 智能体标记为"秘密"
    └── 不出现在任何报告中
```

### 6.2 数据脱敏

```
数据脱敏规则：

├── 报告中的脱敏
│   ├── 姓名 → 昵称或"孩子"
│   ├── 具体对话 → 话题标签
│   └── 敏感词 → ** 替换
│
├── 日志中的脱敏
│   ├── 用户ID → 哈希值
│   ├── 个人信息 → 脱敏
│   └── 不记录完整对话
│
└── 统计分析脱敏
    ├── 使用聚合数据
    ├── 不使用个人数据
    └── 不关联个人身份
```

### 6.3 第三方共享限制

```
第三方共享规则：

├── 不共享给第三方
│   ├── 不出售数据
│   ├── 不共享给广告商
│   └── 不用于其他用途
│
├── 必要共享
│   ├── 法律要求时
│   ├── 家长明确授权
│   └── 服务必需（如云服务）
│
└── 共享限制
    ├── 仅限必要数据
    ├── 签署保密协议
    └── 加密传输
```

## 九、风险应对

### 9.1 潜在风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 数据泄露 | 信任危机、法律责任 | 加密存储、访问控制、安全审计 |
| 未授权访问 | 隐私侵犯 | 严格授权流程、身份验证 |
| 过度收集 | 合规风险 | 最小化原则、定期审查 |
| 未成年人冒用 | 法律风险 | 家长验证、手机号验证 |

### 9.2 应急预案

```
数据安全事件应急预案：

├── 发现阶段
```
