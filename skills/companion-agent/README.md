# 陪伴型智能体项目

## 项目定位

做一个**可定制化的陪伴型智能体框架**，支持多场景适配。

## 产品演进路线

```
阶段1: AI+教育 → 陪伴孩子成长（优先级最高）
    ↓
阶段2: 老人陪伴型
    ↓
阶段3: 单身男女陪伴型
    ↓
阶段4: 心理陪伴（焦虑治疗等）最后做
```

## 核心特性

- **前端配置界面**：用户可选择目标用户、陪伴价值
- **硬件接入渠道**：提供统一的智能家居接入接口
- **纯软件技能**：无需绑定硬件载体
