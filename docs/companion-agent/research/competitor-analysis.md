| 价格高 | 硬件产品价格贵 |
| 无统一平台 | 各设备/应用之间不互通 |

## 四、竞争策略

### 核心差异化

1. **纯软件技能**：不绑定硬件，降低用户门槛
2. **多场景适配**：一个框架，儿童/老人/单身多种场景
3. **情感陪伴**：有性格、有记忆、有温度
4. **开放生态**：可接入各种智能硬件
5. **定制化**：用户可选择角色性格、陪伴价值

### 商业模式（待定）

- 基础功能：免费
- 高级功能：订阅制
- 硬件接入：按设备收费
- 企业版：定制部署
